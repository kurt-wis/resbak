These were the design docs before the game design document (GDD) existed. They are kept
unchanged for history. **Do not implement from them.** Where they disagree with
[`../design/RESBAK_GDD.md`](../design/RESBAK_GDD.md), the GDD is right.

| File | Was | Now in the GDD |
| ---- | --- | -------------- |
| `RESBAK.md` | Design summary of the 5 characters | § Characters |
| `characters/01-05_*.md` | Per-character dossiers with numbers | § Characters, § Numbers at a glance |
| `gameplay/agawan_base_rules.md` | Rules engine spec (freshness, jail, chain, win) | § Core rules, § Player states and timing |

Known differences: the freshness meter became Sigla read from outlines, sprint and stamina
are gone, Batang Hamog is now Tutoy, rescue is by touching the chain tip, and there is no flag.
