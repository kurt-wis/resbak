# Archive: superseded design docs

These were the design docs before the game design document (GDD) existed. They are kept
unchanged for history. **Do not implement from them.** Where they disagree with
[`../RESBAK.md`](../RESBAK.md), the GDD is right.

| File | Was | Now in the GDD |
| ---- | --- | -------------- |
| `RESBAK.md` | Design summary of the 5 characters | § 4 Characters |
| `characters/01-05_*.md` | Per-character dossiers with numbers | § 4 Characters, § 3 Numbers at a glance |
| `gameplay/agawan_base_rules.md` | Rules engine spec (freshness, jail, chain, win) | § 2 Core rules |

Known differences: the freshness rule became Unahan (first clean tag wins, with each team barred from its own base), sprint and stamina
are gone, Batang Hamog is now Tutoy, rescue is by touching the chain tip, and there is no flag.
