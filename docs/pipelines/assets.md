# Assets: where things live and how they flow

```
imported_models/<pack>/        raw prop packs (.glb + albedo + metallic/roughness PNG)
   └─ scripts/map_pipeline/prepare_props.gd ──► assets/props/<name>.tscn + <name>_geometry_1.res
source_art/<character>/        raw character sources (Godot-ignored)
   └─ tools/build_*.py (Blender) ─────────────► assets/characters/<name>.glb
assets/environment/            hand-painted textures used by shaders/*.gdshader
shaders/                       all spatial shaders (toon, outline, painted surfaces, roof cutaway, jail hologram)
```

## Props
8 props: `blue_plastic_chair` (from `blue_monobloc_chair_1k`), `metal_barrier`
(`crowd_barrier_1800tri`), `potted_plant`, `stage_speaker` (`barangay_speaker_900tri_clean`),
`street_tricycle` (`filipino_tricycle_5000tri`), `tarpaulin_bundle`, `tire_stack`, `wooden_crate`.
Each prop scene has a `SolidCollision` body matching its visible mesh.
`scenes/barangay_court.tscn` instances them under `CourtProps` and `StreetDetails`.

**Konstruksyon vehicles** (`assets/props/vehicles/`): `jeepney`, `pickup`, `hauler`, `digger`,
`wheel_loader`, Mathew's Meshy models (raw downloads in `source_art/props/vehicles/`). Each is a
`<name>.glb` plus a `<name>.tscn` wrapper; `scenes/construction_site.tscn` instances the wrapper as a
`Model` child of each vehicle node, which keeps its own `StaticBody3D` box (the prop scenes carry no
collider). Rebuild with `& $env:BLENDER -b --python tools/build_vehicle_props.py` (`-- <name>` for one),
then `tools/qc_asset.py`.

**Home diorama set** (`assets/props/home/`, built by `tools/build_home_props.py`): Meshy `store`,
`facade_teal`, `facade_pink`, `fruit_stall`, `mango_tree`, `coconut_palm`, `graffiti_wall` (raw downloads in `source_art/props/home/`, Godot-ignored) and
16 procedural props (`stool_18/19/24`, `bench`, `bottle_crate`, `power_pole`, `wire_span`, `sign_sari_sari`,
`sign_tindahan`, `sidewalk`, and the hand-held `soda_bottle`, `palamig_bag`, `paper_fan`, `payong`,
`water_gallon`, `backpack`). Each is a `<name>.glb` plus a `<name>.tscn` wrapper; none has collision.
Their colours are graded at runtime by `shaders/diorama_set.gdshader` (the Meshy textures are baked saturated
teal/orange and look plastic ungraded). Home UI art: `assets/ui/home/` (cardboard, tape; `tools/make_home_ui.py`),
`assets/fonts/LuckiestGuy-Regular.ttf`, and `assets/audio/home/` (`tools/make_home_audio.py`).
Ground and skyline façade textures (`ground_*`, `facade_a..e` in `assets/props/home/`) are drawn by
`tools/make_home_ground.py` (PIL, no Meshy); their `.import` files enable mipmaps. The graffiti wall is Meshy
image-to-3D from a nano-banana mural image (29,999 tris after decimation; QC sheet `renders/qc/graffiti_wall_sheet.png`).
Meshy spend for v0.1.2: 465 of the 500-credit cap.

## Characters
Game-ready GLBs in `assets/characters/`; character visuals get `character_toon.gdshader`
applied at runtime (`court_playtest.gd: apply_illustrated_materials`).

Face cards for the Home diorama (painted mouth and eyelid atlases plus a card GLB per hero) live in
`assets/characters/face_cards/`; they are generated by `tools/build_face_cards.py`, see
[blender.md](blender.md#face-cards-home-diorama-talking-2026-10-17).

The four Home bystanders (`tindera`, `lola`, `manong`, `student`) are in `assets/characters/bystanders/`
with Meshy's own rig, see [blender.md](blender.md#bystanders-and-home-set-pieces-2026-10-17).

## Godot sidecar files
- `*.import`: import settings next to every imported asset. Commit them; move them with their asset.
- `*.gd.uid` / `*.uid`: stable resource IDs. **Always move/rename with the `.gd`**.
- `.godot/`: local import cache, gitignored. Rebuild with `& $env:GODOT --headless --path . --import`.

## Git LFS policy (adopted 2026-10-15)
`.gitattributes` routes `*.glb *.png *.jpg *.blend *.res` through Git LFS.
History was **not** rewritten: binaries committed before 2026-10-15 stay as regular git
objects until they're next modified, then they become LFS pointers. Requires
`git lfs install` on each clone.
